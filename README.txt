OLED SERVICE — сборка настольного приложения (.exe)
======================================================

Что в этой папке:
  main.js          — код запуска окна приложения
  package.json     — настройки сборки
  oled_service.html — сама программа (склад)
  icon.ico         — иконка приложения

ЧТО НУЖНО СДЕЛАТЬ (один раз, на своём компьютере):

1) Установите Node.js (если ещё не установлен):
   https://nodejs.org  → скачайте версию "LTS" → установите как обычную программу.

2) Скопируйте всю эту папку (oled-desktop) на свой компьютер, например на рабочий стол.

3) Откройте командную строку (CMD / PowerShell / Терминал) в этой папке:
   - В Windows: откройте папку, в адресной строке проводника напишите "cmd" и нажмите Enter.

4) Введите по очереди и нажимайте Enter после каждой команды:

     npm install
     npm run build

   (первая команда скачает нужные файлы из интернета — подождите пару минут,
    вторая — соберёт готовое приложение)

5) Готовый .exe появится в папке:  dist/
   Там будет файл вида "OLED SERVICE Setup 1.0.0.exe" — это установщик.
   Также будет "OLED SERVICE 1.0.0.exe" (portable) — можно запускать без установки.

6) Установите (или просто запустите portable-версию) — на рабочем столе появится
   ярлык "OLED SERVICE" со своей иконкой, программа будет открываться как
   обычное окно, без браузера, полностью офлайн.

ВАЖНО:
- Все данные хранятся прямо в самом приложении на этом компьютере.
  Если удалите приложение — данные удалятся тоже. Периодически делайте
  резервную копию (Настройки → в будущем можно добавить экспорт).
- Если хотите передать программу на другой компьютер — просто скопируйте
  туда файл "OLED SERVICE Setup 1.0.0.exe" и установите там же.
